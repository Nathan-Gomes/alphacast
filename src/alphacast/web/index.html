    RESEARCH CONTROLS

    How AlphaCast avoids the easy mistakes.

    01 / Features

    Every input is trailing-only and exists at the decision close.

    02 / Target

    Forward sector-relative return starts after the scoring session and runs for 20 sessions.

    03 / Embargo

    The latest 20 labelled sessions are removed from training so labels cannot overlap the test horizon.

    04 / Costs

    Top-ranked portfolio results disclose turnover and subtract declared transaction costs.

    Limits that remain: a manually declared universe can have selection bias; Yahoo is not institutional point-in-time data; there are no fundamental features or execution-quality estimates yet. A positive backtest does not prove future performance.
